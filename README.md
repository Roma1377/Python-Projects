# Python Projects Portfolio

Практические проекты на Python: от базового синтаксиса до ООП и архитектуры приложений.

## 🛠 Стек технологий
* Python 3, ООП, SOLID
* Паттерны проектирования (MVC, Repository, DI)

## 📂 Содержание
* **Python_Basics:** Базовый синтаксис, работа с файлами и алгоритмы.
* **Python_File_Processing:** Парсинг и обработка текстовых данных.
* **Python_Console_Game_Team:** Командная разработка консольной игры.
* **Python_Web_Application_Layered_Arch:** Веб-приложение с разделением на слои (Domain, Data, Web).
